## 🔨 What I've built

| Project | What it does | Stack | Status |
|---|---|---|---|
| [Predictive Maintenance MLOps](https://github.com/codewithkachi/predictive-maintenance-mlops) | Failure prediction as a monitored API: PR-AUC 0.888, cost-tuned threshold (96% recall), SHAP drivers per prediction, from-scratch PSI drift monitor, CI retrains on every push | XGBoost, FastAPI, Docker, GitHub Actions | ✅ |

| [Multi-Agent Incident Triage](https://github.com/codewithkachi/agent-incident-triage) | LangGraph agents that classify, enrich and prioritise incident reports with schema guardrails, PII redaction, cost budgets, human approval gate and trajectory evaluation | LangGraph, Pydantic, FastAPI | ✅ |
| [UK Property Deal Analyser](https://github.com/codewithkachi/uk-property-deal-analyser) | 2.9M Land Registry transactions in SQL + ONS rents -> transparent deal score -> Power BI deal-finder dashboard | DuckDB SQL, pandas, Power BI, DAX | ✅ |
| [Manufacturing Downtime Analysis](https://github.com/codewithkachi/manufacturing-downtime-analysis) | Failure-mode and maintenance cost analysis: two modes carry 70% of a £2.3M cost; Excel KPI report + Power BI spec | Python, Excel, Power BI, DAX | ✅ |
